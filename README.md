## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn
- MongoDB

### Installation
```bash
git clone https://github.com/sojibahmedshorif25-ai/Job-Finder.git
cd Job-Finder
npm install
cp .env.example .env
npm start
```
